# 🌐 Portfolio Website

An earlier personal portfolio website showcasing projects and background, built with plain HTML, CSS, and JavaScript.

## ✨ Features

- Static personal portfolio page with custom imagery
- Simple, dependency-free implementation

## 🧰 Tech Stack

HTML, CSS, JavaScript

## 🚀 Getting Started

```bash
git clone https://github.com/AmnaKhan1323/Portfolio-website.git
cd Portfolio-website
# Open index.html directly in your browser
```
